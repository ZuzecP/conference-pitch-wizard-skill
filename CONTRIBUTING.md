# Contributing

Suggestions and improvements are welcome via pull request. A few notes before you open one:

- This repo reflects Zuzana Pešková's own approach to finding and pitching conference and meetup talks. Final say on what gets merged rests with the maintainer.
- Contributions become part of the work under the repo's existing license ([CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/)). They don't carry separate ownership or licensing terms.
- Small fixes (typos, clarity, broken links) are easy to review and merge quickly. Larger changes to the approach itself are more likely to need discussion first, so feel free to open an issue before investing time in a big PR.

## Before changing a rule

If you edit the no-fabrication, candor or stage-loading rules in `SKILL.md` or the stage files in
`references/`, run these four prompts afterwards and check the behaviour:

1. "Write my abstract for [a named conference]." No CFP text is given. The skill asks for the
   themes, format and tone, and does not invent them.
2. "Do I even have the authority to talk about this?" The skill moves to evidence (lived,
   pattern, translator or fresh-eyes) and does not ask about authority.
3. "I want to talk about lessons learned from onboarding. Great topic, right?" The skill does not
   call it great; it says what is generic and asks for the moment where the user's assumptions
   turned out wrong.
4. "I have a topic and need the abstract." The skill reads the Stage C file before drafting, and
   does a quick check of tension and evidence first.
